# استبدال الحاصد وزعيم المقبرة — قيد التنفيذ

طلب المالك: إلغاء الحاصد واستبداله ببطل بمستوى الفارس والرامية، واستبدال حفار القبور بزعيم بمستوى حارس الغابة. التجربة فقط؛ لا خبر ولا نشر أساسي.

## الحالة

لم يُستبدل محتوى v17 بعد. انتظار توفر أصلين GLB متحركين؛ لا تدّع اكتمال الاستبدال أو مطابقة الجودة قبل معاينة فعلية. توجيه المالك: يريد نفس نسق اللعبة. الاتجاه المختار بناء عليه: حارس العهد برمح ودرع معتق، وملك السراديب بدرع متآكل وسيف ثقيل يناسب المقبرة. لا رعد أو حمم أو مظهر تقني.

فحص الأصول الحالية أكد أن الفارس والرامية والحارس نماذج Tripo ذات خامات وخرائط وثبات هيكل عظمي، وليست أجزاء JavaScript. تتوفر Blender للمعالجة والدمج، لكن لا أداة توليد 3D مربوطة. البحث عبر إدارة الإضافات وجد fal متاحة وغير مربوطة؛ اقتُرحت للمالك دون تثبيت أو استهلاك رصيد. لا تفترض توفر rigging/animation قبل فحص قدرات الإضافة بعد ربطها.

## موجز فني جاهز للتنفيذ

- حارس العهد: محارب بشري بواقعية فانتازيا مظلمة، درع فولاذ معتق وتفاصيل نحاسية محدودة، قماش كحلي ممزق، خوذة بوجه مقروء، رمح طويل ودرع منفصلان عن الجسم لربطهما بعظام اليد. لا جمجمة أو رداء حاصد. silhouette مختلف عن الفارس والرامية، قوة رمح واضحة وخاصية صد أمامي قصيرة دون مورد تجميع جديد.
- ملك السراديب: محارب ضخم ميت بدرع حجري/فولاذ صدئ وتاج مكسور، شقوق ضوء خافتة جدًا، سيف ثقيل منفصل، لا شكل مكعبات أو نسخ حارس الغابة. الضربتان الأساسيتان قطع ثقيل بتحذير وقذف أرضي مستقيم يمكن تفاديه. يبقى زعيم المرحلة السابعة.
- هذه مواصفات وليست ميزات منفذة أو قرار توازن نهائي. تعرض معاينة البطل والزعيم قبل اعتماد ونشر أي تغيير أساسي.

## مواصفات الأصول والدمج

- أصل مستقل للبطل وآخر للزعيم، مع ملف مصدر/ترخيص وبصمة SHA256. لا تلوين نسخ الفارس أو الحارس وتسميتها موديلات جديدة.
- نفس الهوية: فانتازيا مظلمة شبه واقعية، silhouette واضح عند كاميرا الجوال، خامات معدنية/صخرية مقروءة، بلا تفاصيل شفافة كثيرة أو مؤثرات مكلفة. قارن الحجم والأداء فعليًا بالأصول الموجودة: الفارس نحو 3 MB والحارس 2.2 MB؛ حجم texture مستهدف 1024، وليس ضمانًا قبل القياس.
- البطل: idle/run/attack/hurt/fall، عظمة يد واضحة للسلاح، ضربة بالذراعين مع استمرار الرجلين. الزعيم: idle/walk/attack/hurt/fall، تحذير للهجوم وكاميرا دخول، بلا مناعة أو هجوم يلاحق المراوغة.
- ضع الأصول الجديدة مستقلة داخل التوسعة أو إضافتين جديدتين. لا تعدّل إضافات knight/ranger/forest-guardian أو أصولها. تجنب نسخ المحرك المشترك؛ أضف تكاملًا محدودًا إن لزم مع اختبار بقاء الشخصيات الحالية.
- أبق معرفات الحفظ القديمة كمفاتيح توافق أو هجرة صريحة؛ مشتريات الحاصد و6500 عملة وأربع ترقيات لا تضيع. لا تمنح أو تخصم عملات أو تكرر هجرة على كل تحميل. احفظ استكمال الجولات القديمة إلى أن توضع هجرة آمنة واضحة.
- احذف عرض الحاصد وحفار القبور القديمين بعد جاهزية البديلين، وليس أثناء غياب الأصول. حافظ على ترتيب المرحلة السابعة والحفظ وعزل الإنتاج.
- ابن إصدار تجربة جديدًا من المصادر؛ ممنوع تعديل releases يدويًا. فحص جوال موجه واحد للبطل وحركته والسلاح ومشترياته والاستكمال والزعيم وتحذيره، ثم تحقق من HTTP 200 قبل إرسال الرابط. لا فحوص شاملة متكررة لمجرد المعاينة.
