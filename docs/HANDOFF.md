# نقطة التسليم

ابدأ بـ[خريطة المشروع](PROJECT-MAP.md) و`../AGENTS.md`. هذا الملف يجمع سياقًا يدويًا وسجلًا آليًا من GitHub.

## قرارات المالك — يحفظها المساعد

- اللعبة للجوال أولًا؛ اللمس والأداء والمقاسات الصغيرة أهم من الكمبيوتر.
- كل تحسين يفيد اللعب يُذكر في الأخبار، مع توضيح إن كان في التجربة فقط.
- ارفع العمل المصرّح به على GitHub قبل التسليم، وسجّل هنا أي قرار جديد وما بقي أو سبب التوقف ليكمل مساعد آخر.
- التحديث الآلي لا يقرأ المحادثة ولا يحفظ التعديلات المحلية غير المرفوعة؛ لا تعتمد عليه لتسجيل نية المالك أو مهام لم تُنفّذ.

## سياق العمل والمتبقي — يحفظه المساعد

- الأساسية `/` والتجربة `/test/`. إصلاحا شفاء الشامان ومصاص الدماء موجودان في التجربة `clean-20261117-v6` فقط؛ لا تنقلهما للأساسية دون تفويض نشرهما هناك. الإضافات الثلاث مستقلة.
- القرارات الإدارية السابقة منفذة ومنشورة؛ لا تكررها أو تصدّر هوياتها من قاعدة البيانات.
- مسار التطوير الأسرع مدمج: أخبار/وثائق ثابتة بفحص خفيف؛ اللعب/الملفات المجهولة بفحص الجوال. أوامر الكمبيوتر اختيارية؛ التفاصيل في الخريطة.
- الدفعة الحالية تضيف `tools/update-handoff.mjs` وjob التسليم إلى workflow نفسه. يلزم بعد دمجها التحقق أن bot حفظ سجلًا تلقائيًا فعلًا؛ لا تعتبر نجاح PR وحده إثباتًا لكتابة الملف.
- التحقق المحلي لهذه الدفعة: نجاح 156 اختبارًا والتحليل دون أخطاء صياغة، وفحص YAML وworkflow وdiff. نتيجة الجوال وكتابة البوت الفعلية من تشغيل GitHub المرتبط بالمرجع أدناه.
- لا ميزة لعب جديدة معلقة في هذه الدفعة، ولا تعديل لمحرك اللعبة أو قاعدة البيانات أو إعدادات Pages. أي مهام جديدة يدوّنها المساعد هنا قبل رفعها.
