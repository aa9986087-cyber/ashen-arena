# نتيجة تنظيف Ashen Arena — 16 نوفمبر 2026

## الحالة النهائية

أُنجزت مراجعة شاملة ومحافظة لكل وحدات التشغيل: الأساس والبيانات، اللعب، الرسوم والصوت والأصول، المبارزات والتعاون، الواجهات وCSS، وأدوات التجهيز وSQL والبنية. نُفذت التغييرات محليًا فوق الإصلاحات السابقة؛ **لا commit/push إلى GitHub اللعبة، ولا نشر، ولا تغيير Pages أو SQL إنتاج**.

نجح التشغيل الموحد النهائي: **128 اختبارًا سريعًا** و**رحلتا Chromium للهاتف والكمبيوتر**، مع التحليل والـfixtures والتعبئة. صفر فشل أو تخطٍ أو flaky. الزمن المحلي **94.274 ثانية** للخط كاملًا، منها **90.499 ثانية** للمتصفح؛ ليس وعدًا بزمن GitHub Actions. اختبارات المتصفح معزولة عن HTTP/WebSocket الإنتاج ولا تطلب ميكروفونًا. اختبارات الشبكة في VM وقنوات وهمية، وSQL نصي فقط لا PostgreSQL حقيقي.

## ما نُظّف

حُذف `wepCost` بعد إثبات أن المتجر لا يستدعيه وأنه ليس مدخلًا موثقًا للمطور، وحُذف `coopClient` غير المصدر على window وغير المستهلك. حُذف فرع `hold.up` الذي لا تمرر له الاستدعاءات الحالية أي callback، دون حذف pointerdown أو معالجات إلغاء العصا الحية.

أزيلت تهيئة/كتابة `aim` غير المقروءة، و**كتابتَا `wardT` في combat والتعاون** مع حفظ امتصاص الدرع والضرر والمؤثرات. أزيلت حقول `COOP.room/n` و`DSFX.ready` و`Duelist.headBone` و`AVA.at` و`VC.sig` وpeer `id` غير المستهلكة؛ بقيت الهوية من مفاتيح Map والـclosures والعظام الفعلية. أزيلت مجموعة `seen` المؤقتة التي لا تُقرأ في `coopMirror`، والربط المحلي لـkills مع بقاء عنصره ومواضع tuple في البروتوكول.

أزيلت أسماء `VT.slash/bolt/muzzle` غير المقروءة دون حذف بلاطات الأطلس أو الصور، ومعاملان trailing ووسيطاهما غير المستهلكين في `weaponModel/menu2Frame`. حُذفت أسماء catch غير المقروءة فقط دون حذف try/catch/finally أو آثارها. أزيلت ألوان CSS `--night2/--panel/--blood` غير المستخدمة، وأربعة روابط محلية في retarget-swat مع إبقاء تقييم المهيئات المؤثرة وواجهة التصدير.

نتيجة المقارنة مع لقطة ما قبل الجولة: **25 ملف مصدر إنتاج/أداة معدلًا، صافي نقص 830 بايتًا و26 سطرًا**. الأثر الأساسي صيانة وتقليل حالة زائدة، وليس تحسين FPS مثبتًا. أضيفت **62 حالة اختبار** إلى الخط الموجود؛ لم تُضعف أو تُعدل الاختبارات الأصلية، ولم تُضف اعتماديات أو بوابة ثانية.

## ما لم يُحذف ولماذا

**لا ملف كامل أو أصل حُذف.** الأصول الـ139 بقيت مطابقة للتجزئات؛ كل ملفات النماذج والصوت لها مراجع تحميل مباشرة أو ديناميكية أو تدخل ضمن مكتبة وتجهيز موثقين. ملفات SQL وCI وpackage/lock وindex وترتيب السكربتات بقيت مطابقة للّقطة. كل شاشات SCREENS وأهداف data-go موجودة؛ لم يثبت مسار شاشة ميت يبرر إسقاط ميزة.

احتُفظ بالصدارة المخفية لأنها تحت صيانة مؤقتة، وبـmenu/menu2 لأنهما حالتان حيتان، وmkGift وأدوات المختبر لأنها مداخل مطور فعلية. احتُفظ بدعم الترقيات القديمة للحفظ وcallbacks والمعاملات الموضعية وواجهات RPC القديمة وبدائل فشل الصوت والنماذج وإعادة الاتصال.

أصبح عدد المرشحات العالمية اللفظية صفرًا في المسح الاستشاري، دون مرجع عالمي غير محلول جديد. بقيت أربعة self-bindings مصنفة اسميًا في الماسح (`loadWeaponModels/newsAuto/Duelist/DuelBot`): أسماء IIFE منفذة أو أسماء داخل scopes الصفوف، وليست أربع وحدات أو دوال ميتة. بقي 82 مرشح معاملات/catch لأنه يشمل placeholders وتواقيع وأسلوب legacy؛ ليس قائمة حذف آلي.

## المراجعة وحدود التكافؤ

لم تجد المراجعة النهائية عائقًا حرجًا. أُغلق اقتراح wardT المتبقي بعدها، واختبار إضافي فشل قبل حذف الكتابة ثم نجح بعده؛ يثبت الامتصاص الكامل/الجزئي والمؤثرات واستعادة remoteKill حتى عند استثناء kill. فشل UI عابر في لقطة عمل سابقة أُغلق؛ النسخة النهائية الموحدة خضراء.

حذف معاملات trailing يغير `.length`، ولم يوجد مستهلك لهذا الانعكاس. elision لربط kills يحفظ تقدم iterator ومواضع مصفوفات البروتوكول الفعلية، لكنه لا يحفظ getter مصطنعًا لـresult.value؛ retarget تعيد object literal عاديًا، فلا يوجد أثر getter في مسار slot الفعلي. هذه حدود ضيقة موثقة، لا ادعاء تكافؤ لكل monkey patch ممكن.

لا تضمن المراجعة الساكنة والاختبارات انعدام كل كود ميت مستقبلًا أو كل فرع ديناميكي؛ حذف المزيد بلا دليل يخاطر بالميزات. ضغط طويل، Safari/Firefox، GPU/bloom كامل، ميكروفون/WebRTC أو شبكة لاعبين حقيقية وSQL/RLS تحتاج staging منفصلًا.
