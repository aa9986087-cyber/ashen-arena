# Ashen Arena — عينة محلية للفانتازيا المظلمة شبه الواقعية

هذه عينة للفارس وحارس الغابة فقط لاعتماد الاتجاه الفني، وليست اكتمال إعادة تصميم جميع الأبطال والوحوش والعوالم والواجهة. تصميم العوالم وبقية الشخصيات في هذه العينة يبقى كما في لعبتك الحالية.

## التشغيل على الكمبيوتر

فك الضغط، ثم افتح الطرفية داخل المجلد الذي يحتوي index.html وشغّل:

    python3 -m http.server 8080

ثم افتح http://localhost:8080/#lab في المتصفح. في Windows إن لم يعمل python3 استخدم python -m http.server 8080. لا تفتح HTML مباشرة عبر file:// لأن محمل المجسمات يحتاج خادم HTTP.

## التجربة داخل Manus

افتح معاينة مشروع خريطة Ashen Arena، واضغط «تجربة الفارس وحارس الغابة». اختر الفارس، ثم ابدأ الجولة. لاختبار الزعيم بسرعة، افتح المختبر من القائمة ثم اختر «حارس الغابة» من استدعاء الزعماء. أدوات المختبر لا تُحتسب ضمن الصدارة.

المكتبات JavaScript الأساسية مرفقة محليًا في assets/vendor؛ الرسومات والموسيقى وكل أصول التشغيل موجودة داخل الحزمة. الخطوط البعيدة قد تستبدل بخط النظام عند انقطاع الإنترنت.

## عدم النشر وسلامة البيانات

لم تُرفع هذه العينة إلى GitHub ولم تُنشر. نسخة المعاينة والحزمة تضبط connect-src بحيث تمنع الاتصال بقاعدة بيانات Supabase وقنوات الإنتاج. اللعب الفردي والحفظ المحلي يعملان؛ الأونلاين والصدارة الحية ليسا جزءًا من اختبار العرض المحلي. ملفات اللعبة الأصلية لا تحصل على هذا العزل عند النشر إلا بقرار منفصل.

## حدود العينة

المجسمان بدروع وخامات PBR وهيكل عظمي فعلي. لكل مجسم خمس حركات أصلية: الوقوف والحركة والهجوم والإصابة والسقوط. هذه الحركات أساس للتطوير وليست إعادة إنتاج لجميع القدرات الخاصة والتحولات. توجد عظمة معصم حقيقية للسلاح، لكن الهيكل المولد لا يتضمن مفاصل أصابع منفصلة؛ ضبط القبضة الدقيقة والأسلحة الجديدة مرحلة لاحقة عند اعتماد العينة. المعدات وبقية الأصول هي أصول اللعبة الحالية، وليست إعادة تصميم جديدة لها.
