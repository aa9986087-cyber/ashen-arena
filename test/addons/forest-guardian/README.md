# إضافة حارس الغابة

عدّل `config.js` للحجم والاتجاه وأسماء الأنميشن، و`model.glb` للشكل فقط. `height: null` يستعير ارتفاع جسم زعيم الغابة الأصلي من `GEO.boss0` عند طلب التحميل. لا تعدّل الفارس أو الرامي أو زعيمًا آخر. أصل الحارس المخفف من `c0c1701`؛ المصدر والبصمة في `manifest.json`.

الترتيب: سجل `ASHEN_ADDONS`، ثم `forest-guardian/config.js`، ثم المحرك المشترك مرة واحدة بعد `models.js` وقبل `main.js`. الافتراضي تعطيل الإضافة؛ للتجربة `?addons=forest-guardian`.

استدعِ `loadBossActor(0)` عند الحاجة، و`actorBossRender(e,now)` لجسم الزعيم فقط، و`actorBossFrame(now)` لكل إطار، و`actorBossHide(e)` عند موته/إزالته. أبقِ الهالة وشريط الصحة وكاميرا الدخول وتجميد القتال في نسخة الاختبار. لا تحتوي الحزمة زعيم الفارس؛ `loadBossActor(2)` لا يحمّل شيئًا.

تفاصيل الخطافات في `../shared/README.md`. لا تحميل تلقائي ولا تشغيل للمعركة.
