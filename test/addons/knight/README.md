# إضافة الفارس

هذه الحزمة مستقلة؛ عدّل `config.js` لضبط الحجم والاتجاه ومقبض السلاح، و`melee.js` لطابور الضربة، و`model.glb`/`portrait.jpg` للشكل والصورة. لا تعدّل ملفات الرامي أو الحارس أو محرك `shared` عند تعديل الفارس وحده. الأصول من الإصدار `c0c1701`؛ بصماتها ومصدرها في `manifest.json`.

الترتيب: سجل `ASHEN_ADDONS` الذي تملكه نسخة التجربة، ثم `knight/melee.js`، ثم `knight/config.js`، ثم المحرك المشترك مرة واحدة بعد `models.js` وقبل `main.js`. التسجيل لا يفعّل الإضافة؛ الافتراضي تعطيلها، والتفعيل التجريبي `?addons=knight`.

السجل يمرّر `hooks.queueMelee(apply)`؛ القيمة `true` تعني أن الطابور تولى المهمة، و`false` تعني تطبيق خط الأساس فورًا. مرّر كتلة الضربة الأصلية كاملة دون تغيير المدى أو القوس أو الضرر، ثم نادِ `hooks.updateMelee()` بعد تحديث ساعة المحاكاة وفي الإطارات المتوقفة لإلغاء الطابور. نادِ `hooks.clearMelee()` عند بدء جولة جديدة/تبديل اللاعب. الدورة 0.1 ثانية والاصطدام 0.04 ثانية؛ جميع الأعداء داخل القوس يتأثرون في نفس الاصطدام. حركة الرجلين مستقلة عن الذراعين.

الحزمة لا تبدأ اللعب ولا تغيّر الإنتاج. تفاصيل خطافات العرض في `../shared/README.md`.
