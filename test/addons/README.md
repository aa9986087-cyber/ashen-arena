# إضافات Ashen Arena المستقلة

تم فصل التطويرات الثلاثة من آخر نسخة محفوظة `c0c1701`، دون إعادة توليد أو تغيير مجسماتها:

| الإضافة | مصدرها المعتمد | ما تملكه |
|---|---|---|
| الفارس | `knight/` | المجسم، صورته، المقاس والاتجاه، حركة الذراعين وتوقيت الضربة |
| الرامية | `ranger/` | المجسم الزمردي، صورته، معايرة الأنميشن، القوس |
| حارس الغابة | `forest-guardian/` | المجسم الأخف المطوّر، المقاس والاتجاه وربطه بالنوع 0 |

`shared/actor-runtime.js` محرك مشترك واحد لتحميل المجسمات وتحريكها. ليس إضافة رابعة ولا نسخة من اللعبة؛ لا يحمّل مجسمات الإضافات المعطلة ولا يستبدل أبطالًا آخرين.

## النسخة الجديدة

نسخة التجربة الجديدة مبنية من ملفات **اللعبة الأساسية في جذر المستودع**، وليست من ملفات التجارب القديمة. في البداية، جميع الإضافات معطلة (`enabledAddons: []`) لتكون نقطة انطلاق نظيفة. لا انتظار خمس ثوانٍ، ولا عرض تلقائي، ولا اتصال بقاعدة بيانات الإنتاج، ولا مشاركة لحفظ اللاعب مع اللعبة الأساسية.

الإعداد: [`../modular-config.json`](../modular-config.json). البناء من جذر المستودع:

```sh
python3 test/tools/build-modular-test.py
node test/addons/shared/verify-addons.cjs
node test/tools/verify-modular-preview.mjs
```

لتجربة الفارس وحده مستقبلًا، ضع `"enabledAddons": ["knight"]`. للرامية وحدها `["ranger"]`، ولحارس الغابة وحده `["forest-guardian"]`. غيّر رقم `release` عند كل تسليم ثم أعد البناء؛ لا تعدّل الملفات المبنية يدويًا. معاملات `addons` في الرابط مخصصة لفحص المطوّر فقط، وليس تشغيلًا تلقائيًا للمعركة.

## قاعدة تعديل المستخدم

إذا طلب صاحب اللعبة تعديلًا يخص الفارس أو الرامية أو بوس الغابة، عدّل **الإضافة المعنية فقط**، ثم جرّبها في النسخة الجديدة. لا تغيّر الإضافتين الأخريين، ولا تضف التعديلات إلى الأساسية دون اعتماد صريح. الإعدادات والأصول والأنميشن الخاصة بكل إضافة محفوظة في مجلدها مع رقم مصدر وSHA256 في `manifest.json`.

العمل السابق محفوظ في تاريخ Git والفرع `test-v22-saved`. مصدر صفحة التجربة السابقة محفوظ في `test/archive/pre-modular-index.html`، وباقي مجلداتها القديمة تُركت كما هي، خارج أداة بناء النسخة الجديدة.

التعليمات الدائمة: [`../AGENTS.md`](../AGENTS.md). التفاصيل الفنية: [`shared/README.md`](shared/README.md).
