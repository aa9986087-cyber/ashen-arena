# Open models for حلبة النغالة

The prepared assets use CC0 1.0 sources.

- `figures.glb` combines the [MakeHuman base mesh, adult male targets and weights](https://github.com/makehumancommunity/makehuman/tree/a8bc2d54ff0ac92e78ff71431b1023eda42bf482/makehuman/data) with the Quaternius [Universal Base Characters Standard](https://quaternius.com/packs/universalbasecharacters.html) animation rig. The rig source is `character.glb`, mirrored by [programasweights/avatar](https://github.com/programasweights/avatar/blob/main/ASSETS.md), SHA-256 `d6f3b64cab629f6ddca9ba063811aeffd3663a8a4e49ade47cd9505dc2bbd70f`. The lower-body garment is Margaret Toigo’s `toigo_wool_pants` with its original mesh, UVs and texture from [MakeHuman Pants 01](https://static.makehumancommunity.org/assets/assetpacks/pants01.html), CC0. The included MakeClothes bindings fit the asset to the fighter dimensions and transfer the existing leg weights. The asset license from MakeHuman is in [CC0-MAKEHUMAN.md](CC0-MAKEHUMAN.md).
  To regenerate, put `3dobjs/base.obj`, `rigs/default_weights.mhw` (as `weights.json`), and the three `targets/macrodetails/*.target` files listed in `makehuman-upper.py` in a single directory. Extract the `clothes/toigo_wool_pants` folder from the Pants 01 download. With NumPy and Pillow installed, run `python3 -B tools/prepare-figure.py <rig.glb> <makehuman-directory> <toigo_wool_pants-directory> assets/figures.glb`.
- `weapons.glb` uses the original FBX downloads from the Modular Weapons Pack. The build brings each mesh to the size of the game’s hand, keeps its material colors, and names the prop with its duel ID. Exact author filenames and grip positions are in `../tools/prepare-weapons.py`. [Original pack](https://quaternius.com/packs/medievalweapons.html)

The WebP catalog images render the gameplay models locally. To regenerate them, build the preview and run `node tools/render-portraits.mjs <build-directory> assets` from this expansion.
