# حلبة النغالة

معاينة مستقلة لمبارزة ساحة الرماد مبنية من مرجع الرسمية المثبّت في `build.py`.

- خمس هيئات من الأقمشة المدعّمة والأحزمة والأحذية والصفائح، مع معاينة من مجسّمات اللعب في شاشة التجهيز. البداية من منظور خلف الكتف، ويمكن تغييره.
- اسحب زر «النصل» لتغيير اتجاه اليد والسلاح أثناء الحركة. اللمس لضربة سريعة والضغط المطوّل للقوية. كل سلاح يستجيب حسب كتلته، والصد يتطلب التقاطع مع نصله.
- لكل طرف مقاطع تلامس مستقلة تتبع حركة العظام. قطع النصل يترك أثرًا ونزيفًا في مكان الاصطدام، والضربة الراضّة تترك كدمة. إصابة الساق تخفّض سرعة الخطوة، وإصابة الذراع تخفّض سرعة النصل وقوة الضربة. السقوط يتأثر باتجاه الضربة ويظل منظور اللعب مفتوحًا وهو يفلت السلاح.
- مؤثرات الإصابة لها وضع خفيف وكامل. عناوين الجولة تذكر الإصابة التي حسمت النتيجة إذا كانت الجولة قد انتهت بالضربة.
- في النسخة المستضافة، يعطي زر فتح الغرفة رمزًا لصديقك. للتجربة المحلية بين تبويبين، افتح نفس العنوان مع `?local=1`. مفاتيح الحفظ وقناة الغرف منفصلة عن الرسمية. ملف الجوال الواحد مخصص للتدريب.

```bash
python3 test/expansions/iron-duel/build.py /tmp/iron-preview --mobile-file /tmp/iron-duel.html
python3 -m http.server 8080 --directory /tmp/iron-preview
IRON_CHROMIUM=/usr/bin/chromium node test/expansions/iron-duel/verify.mjs /tmp/iron-preview
```

مصادر المجسّمات وتعليمات إعدادها موجودة في [ملف الأصول](assets/SOURCES.md).
