# حلبة النغالة

معاينة مستقلة لمبارزة ساحة الرماد مبنية من مرجع الرسمية المثبّت في `build.py`.

- ثلاثة دروع ومظهران خفيفان بسروال قماش مستقل عن الجسم، في قائمة تجهيز مقسمة إلى المقاتل والأسلحة والأونلاين. البداية من منظور خلف الكتف، مع إمكانية تغيير المنظور.
- المس زر «النصل» لضربة سريعة أو اضغط مطولًا للقوية. اسحب الزر بأي اتجاه لتوجيه يد المقاتل ونصله أثناء الضربة. السلاح الأثقل يستجيب أبطأ، ويرتد عند الاصطدام. يمكنك التحرك أثناء السحب.
- ثلاثة عشر سلاحًا من حزمة Quaternius CC0، مع صور من المجسّمات وتصفية القطع والطعن والطرق. حساب التلامس يستخدم طول الجزء الضارب ومكانه في السلاح. السرعة والكتلة وموضع الإصابة تؤثر على الضربة. الصد يتطلب تلامس النصلين، وتتغير إضاءة الساحة مع خامة الحجر ولون المعدن. مؤثرات الإصابة لها وضع خفيف وكامل.
- في النسخة المستضافة، يعطي زر فتح الغرفة رمزًا لصديقك. للتجربة المحلية بين تبويبين، افتح نفس العنوان مع `?local=1`. مفاتيح الحفظ وقناة الغرف منفصلة عن الرسمية. ملف الجوال الواحد مخصص للتدريب.

```bash
python3 test/expansions/iron-duel/build.py /tmp/iron-preview --mobile-file /tmp/iron-duel.html
python3 -m http.server 8080 --directory /tmp/iron-preview
IRON_CHROMIUM=/usr/bin/chromium node test/expansions/iron-duel/verify.mjs /tmp/iron-preview
```

مصادر المجسّمات وتعليمات إعدادها موجودة في [ملف الأصول](assets/SOURCES.md).
